# v2.4 生产发布检查清单

## 发布前

- 确认目标提交已合并到 `main`，工作区无未提交文件。
- 确认生产 `.env` 已设置 `DATABASE_URL`、`REFEREE_ADMIN_PASSWORD_HASH`、`REFEREE_ADMIN_SESSION_SECRET`、`REFEREE_MEMBER_SESSION_SECRET`。
- 管理员密码和两个 Session Secret 必须在线下生成，互不复用，不进入 Git、终端历史或日志。
- 暂停应用写入后执行 `npm run db:backup`，确认 `backups/` 中生成备份且备份文件未被 Git 跟踪。
- 记录发布前 Git 提交、数据库备份绝对路径和 PM2 状态。

## 发布

1. `git fetch origin && git checkout main && git pull --ff-only origin main`
2. `npm ci`
3. `npx prisma migrate deploy`
4. `npm run build`
5. `test -f .next/BUILD_ID`
6. `pm2 restart nuaa-football --update-env && pm2 save`

## 验收

- `npm run health:check`
- 检查首页、新生杯新闻与公告、协会现任成员、影像资料二维码。
- 检查管理员和裁判员登录失败信息不泄露账号或配置状态。
- 检查开放场次、报名、选派发布/撤回、公开名录、CSV 和打印页的权限边界。
- 检查 `pm2 status`、`pm2 logs nuaa-football --lines 100`、`curl -I https://nuaafa.cn`。

## 回退

- 代码回退只影响应用文件，不自动回退数据库。
- 若新版本应用异常但迁移成功，先切回发布前提交并重新构建、重启 PM2；新增字段和表可保留。
- 只有确认必须恢复数据库时，先停止 PM2，再保留故障数据库副本，使用发布前备份覆盖生产 SQLite 文件，然后切回对应提交、构建并启动。
- 恢复后再次执行健康检查和关键页面验收。
