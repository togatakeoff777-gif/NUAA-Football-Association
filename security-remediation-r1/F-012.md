## 实现方式

- 发布事务把当前最终 selected referee set 中的非 terminal application 状态统一为 `APPOINTED`。
- 同场不在最终 selected set、但残留为 `APPOINTED` 的 application 统一降为 `NOT_SELECTED`。
- `WITHDRAWN` 与 `REJECTED` 明确不在两个 update 集合中，保持 terminal application 语义。
- 两组 application 更新与 appointment version/status 更新处于同一 Prisma transaction。

## 新增测试

- `publish A -> withdraw -> replace A with B -> republish`: A=`NOT_SELECTED`, B=`APPOINTED`。
- `publish A+B -> withdraw -> remove A/add C -> republish`: A=`NOT_SELECTED`, B+C=`APPOINTED`。
- 同场 `WITHDRAWN`、`REJECTED` application 在 republish 后保持原状态。

- terminal application statuses preserved: PASS
