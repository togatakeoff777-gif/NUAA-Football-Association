## 实现方式

- `RefereeApiInputError` 标识可信 validation 4xx；既有 `RefereeServiceError` 保留 domain status/message/warnings。
- `refereeApiErrorResponse()` 对 typed errors 保留现有 4xx contract。
- `SyntaxError`（malformed JSON）统一为固定 400，不回显解析器信息。
- unexpected error 统一返回固定 fallback 与 HTTP 500；member/legacy admin 返回 `code=INTERNAL_ERROR` 与 correlation id，公开 admission 为兼容冻结 contract 仅返回固定 `error`，correlation id 只进入脱敏日志。
- server log 仅记录 correlation id 和严格字符集过滤后的 error class name；不记录 message、stack、SQL、path、request body、password、cookie、token 或 Authorization。
- Unified Admin mapper 复用同一 unexpected-error implementation；SEC-04 的安全行为不被放宽。
- legacy authorization、export、login/logout 及全部 member/legacy mutation catch 均接入 safe mapper；不再使用 unknown `error.message` 构造客户端响应。

## Regression tests

- `scripts/test-security-api-errors.ts`：typed 400/409 保留；模拟 Prisma、SQLite、filesystem、programming error 与恶意 error name 均固定 500，客户端/日志 forbidden fragments 均为 0。
- `scripts/test-security-http-fault-worker.ts`：production-mode 服务指向不可打开的隔离数据库，member login、admin login、public admission、legacy authorization 均真实返回 safe 500。
- 正常 member malformed JSON 返回 typed 400。
- 静态扫描 referee member/legacy routes 不再存在 unknown `error.message` ternary 或 raw `console.error(error)`。
